# ITDS241 สรุปปลายภาค

เว็บสรุปวิชา ITDS241 Web Technologies and Applications สำหรับสอบปลายภาค ครอบคลุม Lect09 ถึง Lect14 และแลป Lab09 ถึง Lab14

- L09 Node.js Part I: module, path, url, fs, http server
- L10 Express: routing, static files, form GET/POST
- L11 .env, cookie, session, MySQL (mysql2)
- L12 Web Services: HTTP, JSON, storage, REST, fetch
- L13 REST API ด้วย Node.js: CRUD, CORS, JWT, Axios
- L14 React: JSX, props, state, lifecycle, event, form

แต่ละบทแยกหน้าและสอนด้วยโค้ดทีละขั้น มีหน้าแลปแยก Lab09 ถึง Lab14 ที่อธิบายโค้ดที่ส่งจริงทีละช่วงพร้อมจุดที่ควรแก้ มีชีทท่องจำและข้อสอบฝึก 65 ข้อ

## วิธีเปิด

เปิดไฟล์ `index.html` ด้วย browser ได้เลย ไม่ต้องติดตั้งอะไร ถ้าเปิด GitHub Pages ให้ repo นี้ (Settings › Pages › Deploy from branch `main`) ก็จะอ่านผ่านลิงก์ได้

เนื้อหาสรุปจากสไลด์ของ Faculty of ICT, Mahidol University ข้อสอบฝึกแต่งขึ้นเองจากเนื้อหา ไม่ใช่ข้อสอบจริง
